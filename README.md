# Educação Ambiental — Zero Papel



## Executar localmente

Você pode abrir `index.html` diretamente no navegador. Para uma experiência mais próxima de um servidor web, use a extensão **Live Server** do VS Code.

## Publicar no Vercel

1. Extraia o arquivo ZIP.
2. Envie a pasta para um repositório no GitHub (ou importe a pasta pelo fluxo disponível no Vercel).
3. No Vercel, escolha **Add New → Project** e importe o repositório.
4. Como é um site estático, não precisa configurar framework nem comando de build.
5. Confirme a publicação.

O arquivo `vercel.json` já está incluído.

## Estrutura

- `index.html` — conteúdo e estrutura semântica.
- `styles.css` — identidade visual e responsividade.
- `script.js` — menu mobile e navegação ativa.
- `vercel.json` — configuração simples de URLs para Vercel.

## Personalização

- Textos: edite o `index.html`.
- Cores, espaçamentos e layout: edite as variáveis no início de `styles.css`.
- Imagens: as imagens de capa são carregadas de URLs do Unsplash. Para hospedar tudo localmente, baixe imagens licenciadas/adequadas, coloque-as em `assets/` e atualize os endereços no CSS.

## Observação sobre o conteúdo

O conteúdo foi organizado a partir do PDF enviado. Números, datas, instituições e referências legais foram mantidos como apresentados no material, sem verificação externa independente. Antes de usar o site como material oficial ou público, recomenda-se conferir especialmente dados estatísticos de 2025/2026 e a vigência/interpretação das normas citadas.
